Status: `MOCK` / `DEMO`

Intent:
- `chain_a` is a simple query-plus-homolog A3M.
- `chain_b` is a second simple query-plus-homolog A3M.

Constraints:

- Query rows are first in each A3M file.
- Only supported residue and gap characters are used.
- No claim of real homolog discovery.
